# libDemech2Sharp

The code in this package (built as Demech2.dll) is derived from demech2 (https://github.com/anpage/demech2), a
decompilation of MechWarrior 2, and is licensed under the GNU Lesser General Public License v3.0 (see LICENSE).

Demech2.dll is a separate, replaceable library: applications use it only through its public API and the
interfaces in Runtime/Host/, so a modified Demech2.dll built from this source can be dropped in its place.
